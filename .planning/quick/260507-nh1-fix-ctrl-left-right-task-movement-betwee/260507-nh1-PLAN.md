```rust
/// Extracts @context and +project tag tokens from a pane filter query string.
/// Non-tag terms (due:today, priority, negated `-@foo`, `-+bar`, slash-forms) are ignored.
/// Returns an empty Vec for unfiltered panes (empty filter_query).
fn extract_tag_tokens(filter_query: &str) -> Vec<String> {
    filter_query
        .split_whitespace()
        .filter(|t| {
            (t.starts_with('@') || t.starts_with('+'))
                && !t.starts_with("-@")
                && !t.starts_with("-+")
                && !t.contains('/')
        })
        .map(|t| t.to_string())
        .collect()
}
```

**Change C — Replace validation + mutation blocks in `pane_move_task`**:

Replace the two `is_single_tag_token` guard blocks (the two `if !Self::is_single_tag_token(...)` blocks that push warnings and return early) with:

Replace the mutation block (the `filtered_tokens` / `new_raw` section inside the `for &task_idx` loop) with the generalized multi-token version:
```rust
// Remove all source tag tokens from raw (word-exact match, case-sensitive).
let mut new_raw: String = raw
    .split_whitespace()
    .filter(|&t| !src_tags.iter().any(|s| s == t))
    .collect::<Vec<_>>()
    .join(" ");

// Append each dest tag token if not already present.
for dest_tag in &dest_tags {
    let already_present = new_raw.split_whitespace().any(|t| t == dest_tag.as_str());
    if !already_present {
        if !new_raw.is_empty() {
            new_raw.push(' ');
        }
        new_raw.push_str(dest_tag);
    }
}
```
