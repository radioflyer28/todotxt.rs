# Quick Task 260508-l56: remove line numbers from task list display - Context

**Gathered:** 2026-05-08
**Status:** Ready for planning

<domain>
## Task Boundary

Remove the `N:` line-number prefix from each task row in the main task list display.
Line numbers are display-only; no keyboard shortcut, jump-to-line, or external hotkey uses them.
Users who need to reference line numbers can use the external editor option.

</domain>

<decisions>
## Implementation Decisions

### Scope of removal
- Remove only the inline `N:` prefix on each task row in the main list (`app.rs` line ~3688).
- The pane secondary lists (`pane_list.rs`) already have no line numbers — no change needed there.
- Status bar aggregate counts (e.g. "42 tasks | 5 selected") are KEPT — only per-row numbering removed.

### Format string change
- Current: `format!("{}{}{}: {}", prefix, indent, ci + 1, t.to_raw())`
- Target:   `format!("{}{}{}", prefix, indent, t.to_raw())`

### Agent's Discretion
- Test update: any existing test asserting on row content containing `N:` pattern must be updated.

</decisions>

## Specific Ideas

- Single-line change in `app.rs` `build_display_items` / task row rendering block (line ~3688).
- Search tests for assertions matching `"1: "` or `format!(...ci + 1...)` patterns and update them.
