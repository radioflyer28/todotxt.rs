## What Changed Since Revision 2

### Phase 31 Execution (2026-04-29)

**Status:** ✅ Complete

**Gaps Closed:**
1. **GAP-1 (Critical):** Single-pane/panes_hidden render regression
   - **Root Cause:** Phase 25 moved filter/sort/group hotkey writes to per-pane state, but rebuild_display_indices() still read from global fields (never updated)
   - **Fix:** Phase 31 added sync block in rebuild_and_reanchor() to copy active pane state to global before rendering
   - **Result:** Single-pane and panes_hidden modes now correctly apply filters/sorts ✅

2. **GAP-2 (Minor):** FilterDefining panel pre-fill
   - **Root Cause:** app.rs line 833 read &self.filter_query (global, always empty) instead of active pane's filter
   - **Fix:** One-line change to read from active_pane().filter_query
   - **Result:** FilterDefining panel (F key) now shows active pane's current filter ✅
