## Milestone Summary

**Key Decisions:**
- `suppress_future_threshold` already existed in `todotxt-core` — no core changes needed for `t:` CLI support
- `App::new` signature extended to accept `TuiConfig + config_path` (Phase 16) — Phase 17 compiled against this cleanly
- `G` jump-to-bottom shortcut removed after UAT feedback to avoid `g/G` conflict expectations
- Group headers use subtle gray styling (not `REVERSED`) — cleaner visual hierarchy

**Issues Resolved:**
- Theme `t` key did nothing at runtime — added `cycle_theme()` handler with config persistence
- Arrow keys in edit mode and F panel did not work — switched `input_without_shortcuts` → `input`
- Preset slot numbering drifted (f2 stored as f1 when f1 empty) — replaced with deterministic `f1..fN` iteration
- F panel Enter always applied row 0 — fixed to apply focused row's filter value

**Issues Deferred:**
- Nyquist VALIDATION.md for phases 14–17 (process gap; functional coverage exists via 31 integration tests + 21-suite run)
- Windows temp-file locking race in `test_deduplicate_multiple_duplicates` (pre-existing, not a v1.2 regression)

**Technical Debt Incurred:**
- Phase 16 VERIFICATION.md was never filled in (remains placeholder) — coverage provided by UAT instead
- Phases 14/15 have no VERIFICATION.md at all — work verified by integration tests and UAT
