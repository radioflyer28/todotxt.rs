Define `LineEnding` enum:
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LineEnding {
    Lf,
    CrLf,
}

impl LineEnding {
    pub fn as_str(&self) -> &'static str {
        match self {
            LineEnding::Lf => "\n",
            LineEnding::CrLf => "\r\n",
        }
    }
}
```

Define `TaskList` struct:
```rust
pub struct TaskList {
    path: PathBuf,
    tasks: Vec<Task>,
    line_ending: LineEnding,
    preserve_whitespace: bool,
}
```

Implement `TaskList::load(path: impl AsRef<Path>) -> Result<Self, TodoError>`:
- Read entire file as `String` (propagate I/O errors as `TodoError::Io { path, source }`)
- Strip UTF-8 BOM: if content starts with `\u{FEFF}`, strip it
- Detect line ending: scan first 4000 bytes for `\r\n` (→ CrLf) or `\n` (→ Lf). Default to `Lf` if no newline found.
- Split content by detected line ending
- Parse each line with `Task::parse(line)`
- If `preserve_whitespace` is false (default), skip empty lines
- If `preserve_whitespace` is true, keep blank lines as Tasks with empty raw/body
- Return `TaskList { path, tasks, line_ending, preserve_whitespace: false }`

Implement `TaskList::load_with_options(path: impl AsRef<Path>, preserve_whitespace: bool) -> Result<Self, TodoError>`:
- Same as load but with configurable `preserve_whitespace`

Implement `TaskList::save(&self) -> Result<(), TodoError>`:
- Create `tempfile::NamedTempFile::new_in(self.path.parent())` — same directory as target for atomic rename
- Write each task as `task.to_string()`, joined by `self.line_ending.as_str()`
- Add trailing newline (line ending after last task)
- `flush()` then `sync_all()` on the inner file
- `temp_file.persist(&self.path)` for atomic replacement
- Map I/O errors to `TodoError::Io`

Implement CRUD methods:
- `pub fn add(&mut self, task: Task) -> Result<(), TodoError>`: push to `self.tasks`, then `self.save()`
- `pub fn update(&mut self, index: usize, new_task: Task) -> Result<(), TodoError>`: bounds check (return `TodoError::IndexOutOfBounds` if index >= tasks.len()), replace `self.tasks[index]`, then `self.save()`
- `pub fn delete(&mut self, index: usize) -> Result<(), TodoError>`: bounds check, `self.tasks.remove(index)`, then `self.save()`
- `pub fn reload(&mut self) -> Result<(), TodoError>`: re-read file, re-parse, update `self.tasks` and `self.line_ending`

Implement getters:
- `pub fn tasks(&self) -> &[Task]` — returns slice, NOT `&Vec<Task>`
- `pub fn len(&self) -> usize`
- `pub fn is_empty(&self) -> bool`
- `pub fn path(&self) -> &Path`
- `pub fn line_ending(&self) -> LineEnding`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File system → TaskList | Untrusted file content read from user's todo.txt (could be corrupted, BOM-prefixed, or externally modified) |
| TaskList → File system | TaskList writes back to disk (must be atomic to prevent corruption) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | task_list.rs save() | mitigate | Atomic write via `tempfile::NamedTempFile::persist()` — original file is never truncated mid-write. If process is killed, either old or new file exists, never partial. |
| T-01-02 | Tampering | task_list.rs CRUD | mitigate | Index-based identity for delete/update prevents silent deletion of wrong task when duplicates exist (fixes C-1 bug). Bounds checking returns error instead of panicking. |
| T-01-03 | Information Disclosure | task_list.rs temp file | accept | Temp file created in same directory as target. File permissions inherit from directory. Acceptable for a single-user local tool. |
| T-01-04 | Denial of Service | task_list.rs load() | accept | Large files consume proportional memory. Acceptable for a local CLI tool — user controls their own files. No network exposure. |
</threat_model>
