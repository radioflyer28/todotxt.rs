## v1 Requirements (archived)

### Capture Friction and Fast Entry

- [x] CAP-01: Add-task flow remains instant with minimal mode switching and predictable keybindings.
- [x] CAP-02: Edit-task flow remains fast and consistent with add-task key behavior.
- [x] CAP-03: Pressing `s` opens a due-date picker that can set or overwrite `due:` on active or selected tasks.
- [x] CAP-04: Pressing `i` opens a priority picker that can set or overwrite priority `(A-Z)` on active or selected tasks.
- [x] CAP-05: Property edits preserve non-target metadata (`@context`, `+project`, creation/completion fields).

### Quick Context and Project Setters

- [x] TAG-01: Pressing `@` in normal mode opens a quick context setter for active or selected tasks.
- [x] TAG-02: Pressing `+` in normal mode opens a quick project setter for active or selected tasks.
- [x] TAG-03: Quick tag setters avoid duplicate tokens and preserve all non-target metadata.
- [x] TAG-04: Context/project setters show autocomplete matches while typing, including potentially redundant near-matches.
- [x] TAG-05: Autocomplete supports arrow-key selection and tab-to-complete for fast token entry.

### Date Autocomplete and Picker Guidance

- [x] DATE-01: Typing partial due tokens such as `due:2026-` or `t:2026-07-` shows valid numeric day suggestions for the target month.
- [x] DATE-02: Date suggestions display weekday labels next to each suggested day.
- [x] DATE-03: Date autocomplete supports arrow-key selection and tab-to-complete in date entry flows.
- [x] DATE-04: The `s` due-date setter uses the same month-aware day options and weekday labels as typed date autocomplete.

### Safe Bulk Actions

- [x] BULK-01: High-impact bulk actions (overwrite, cut, delete) display affected-count preview before execution.
- [x] BULK-02: Bulk actions provide a clear cancel path and leave data unchanged on cancel.
- [x] BULK-03: Bulk action targeting remains stable for multi-selection and grouped/pane views.

### Basic Clipboard Workflows

- [x] CLIP-01: Copy action copies selected task line text in todo.txt-compatible raw form.
- [x] CLIP-02: Cut action copies selected task line text, then removes selected tasks after confirmation rules are applied.
- [x] CLIP-03: Paste action creates new task entries from one or more clipboard lines.
- [x] CLIP-04: Pasting is supported during new-task entry (`n`) to quickly duplicate and tweak tasks.

### Recovery Path

- [x] UNDO-01: Short-horizon undo is available for recent destructive/high-impact actions.
- [x] UNDO-02: Undo restores both task content and selection state for the reverted action where feasible.
- [x] UNDO-03: Undo feedback is clear (what was reverted) and safe (no-op message when history is empty).

### Metadata Flexibility and Views

- [x] META-01: Context and project metadata remain plain todo.txt tokens (`@context`, `+project`) with no new custom schema.
- [x] META-02: Hierarchical tag conventions like `@email/waiting` and `+client/acme` are accepted as ordinary tokens and remain queryable.
- [x] VIEW-03: Existing filter/sort/group views continue to work consistently after capture, bulk, clipboard, and undo flows.
