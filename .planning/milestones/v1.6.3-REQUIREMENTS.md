# Requirements Archive: v1.6.3

**Defined:** 2026-05-15
**Archived:** 2026-05-19
**Core Value:** A fast, cross-platform todo.txt tool with a first-class CLI for both human and AI agent use.

## Final Requirement Outcomes

### Recurring Tasks

- [x] **REC-01**: User can include a `rec:` token on a task with documented interval syntax for strict (`+1d`) and relative (`1d`) recurrence modes.
- [x] **REC-02**: Completing a recurring task automatically creates the next occurrence without prompting.
- [x] **REC-03**: Completing a recurring task creates a new incomplete task with updated recurrence fields and next due date.
- [x] **REC-04**: CLI `do` command and TUI completion paths both apply the same recurring completion behavior.

### Done Rotation

- [x] **DONE-01**: `done.txt` rotates during archive writes when a new configured time period begins, with monthly cadence shipping first.
- [x] **DONE-02**: Rotation preserves prior archived entries in deterministic period-named files and starts a fresh active `done.txt`.
- [x] **DONE-03**: Users can configure archive rotation cadence with safe defaults, while retention cleanup remains out of scope for v1.6.3.

### Filter Language

- [x] **FILT-01**: Filter supports OR logic within a token via `|` (for example `@work|@home`).
- [x] **FILT-02**: OR terms can be combined with space-separated AND terms without breaking existing behavior.
- [x] **FILT-03**: Negated OR terms are supported and documented.

### TUI Usability

- [x] **TUI-01**: Inactive panes do not render cursor highlight while preserving each pane's last selected row.
- [x] **TUI-02**: Grouped views render a spacer row before each non-first group header to improve scanability.

### Date Picker Ergonomics

- [x] **DATE-UX-01**: User can apply the date setter workflow to real date-bearing fields such as due, threshold, and completed dates without repeated command or navigation friction.
- [x] **DATE-UX-02**: Left and right arrow navigation in the date picker jumps by week to make calendar movement faster.

### Match Dialog Auto-Select

- [x] **AUTO-SEL-01**: Match-driven dialogs auto-select the most relevant existing project/context token or suggestion when presented to the user.
- [x] **AUTO-SEL-02**: Auto-select behavior prefers continuity by selecting the current or best matching token instead of resetting to an arbitrary suggestion.

## Requirement Notes

- The earlier milestone wording for recurring completion was corrected during Phase 48 discussion:
  next-occurrence creation is implicit, not prompt-based.
- Date ergonomics remained explicitly TUI/core scoped after Phase 50 corrected an initial
  mistaken desktop-client start.
- Archive rotation shipped as time-based monthly cadence only; retention cleanup remained
  intentionally deferred.
