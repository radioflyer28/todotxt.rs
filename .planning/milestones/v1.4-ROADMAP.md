## Overview

v1.4 introduced keyboard-first Kanban-style vertical panes to the todotxt-tui. Each pane is an independent view with its own filter query, sort order, and grouping. Pane lifecycle controls (create, delete, hide/show), config-defined pane defaults, and CLI path overrides shipped alongside the core pane model. The milestone closed with a thorough audit pass (Phases 28–31) and a post-audit polish round (Phase 32) fixing hotkey regressions, delete ergonomics, and pane label editing before archival.

## Milestone Summary

**Key Decisions:**

- Multi-pane layout uses horizontal splits in ratatui with each pane as an independent `Pane` struct (no shared filter/sort state).
- Pane IDs are zero-based monotonic; re-normalized after deletion to close gaps.
- Single-pane and panes_hidden paths bridge to per-pane state via `rebuild_and_reanchor()` (GAP-1 fix) rather than a separate code path.
- Hotkey matching uses exact modifier flags; loose matching caused Ctrl+N/W/P to fall through in earlier implementation.
- Task index display removed from rendered rows; canonical index lookup routes all mutations through active-pane-aware selection.

**Issues Resolved:**

- FAIL-1: FilterDefining wrote filter to global state, not active pane (fixed Phase 28)
- WARN-1–4: Various per-pane consistency and draw dispatch issues (fixed Phase 28)
- GAP-1: Single-pane/panes_hidden render consumed stale global filter/sort/group (fixed Phase 31)
- GAP-2: FilterDefining pre-fill read from global instead of active pane (fixed Phase 31)
- Exit 101 crash on delete with stale inactive-pane indices (fixed Phase 32)
- Delete/Backspace key aliases and immediate single-delete ergonomics (Phase 32)

**Issues Deferred:**

- Phases 19–22 VERIFICATION.md files marked `human_needed` (v1.3 carryover — acknowledged at v1.4 close)
- SEED-005: Unit tests for Phase 22 manual-only Nyquist gaps (dormant — acknowledged at v1.4 close)

**Technical Debt Incurred:**

- Phases 24 and 26 remain `nyquist_compliant: false` due to layout and pane-lifecycle behaviors that are inherently manual-only; no automated regression coverage for visual pane rendering.
