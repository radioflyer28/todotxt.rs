## Configuration

**Application Settings:**
- `Client\app.config` — Default user settings (FilePath, sort order, window dimensions, font preferences, filter presets, feature toggles)
- `Client\User.settings` / `Client\User.Designer.cs` — Typed settings accessor generated by Visual Studio
- `Client\PortableSettingsProvider.cs` — Overrides default settings provider to write settings XML next to the `.exe` (portable mode)
- Settings file written at runtime: `<exe-dir>\todotxt.settings`

**Logging:**
- Log file: `%AppData%\Hughesoft\todotxt.exe\log.txt` (see `ToDoLib\Log.cs`)
- Log level: `Error` or `Debug`, controlled via `User.settings` (`DebugLoggingOn`)

**Build:**
- Solution: `ToDo.Net.sln` (Visual Studio 2013 format, `Format Version 12.00`)
- Build script: `Build.proj` (root, uses MSBuild Community Tasks)
- Output paths: `bin\Debug\` / `bin\Release\` per project

## Platform Requirements

**Development:**

- NuGet package restore for `NUnit` and `Unofficial.Microsoft.mshtml`

**Production:**
- Windows (XP/Vista/7/8/10) — WPF desktop app targeting x86
- .NET Framework 4.0 Client Profile required (installer checks and prompts download from `http://www.microsoft.com/en-us/download/details.aspx?id=17851`)
