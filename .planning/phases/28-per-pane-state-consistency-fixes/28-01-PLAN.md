<objective>
Fix five per-pane state consistency bugs in app.rs and add an integration test confirming the PANE-03 fix.

**Purpose:** These are gap-closure fixes from the v1.4 milestone audit. PANE-03 has a code defect (FAIL-1): `handle_filter_defining_key` writes to global `self.filter_query` instead of `active_pane_mut().filter_query`, so the FilterDefining panel (`F` key) silently fails to update the active pane's task list. PANE-04 has a related issue (WARN-2): non-Normal mode `draw()` arms render the global task list behind dialogs. WARN-1 causes the status bar to show per-pane filter info even when panes are hidden (inconsistent with the actual task area). WARN-3 means only the active pane rebuilds on task mutations, leaving sibling panes stale. WARN-4 means `rebuild_and_reanchor` reanchors only global `self.selected`, not the active pane's cursor.

**Output:** Modified `app.rs` and new integration test. All `cargo test -p todotxt-tui` tests pass.

```rust
/// Rebuild display rows for ALL panes using each pane's own filter/sort/group state.
///
/// Call after any task_list mutation to keep sibling panes fresh (WARN-3 fix, Phase 28).
pub fn rebuild_all_panes(&mut self) {
    let pane_count = self.panes.len();
    for idx in 0..pane_count {
        // Extract pane parameters into owned locals before touching task_list (borrow splitter).
        let filter_query = self.panes[idx].filter_query.clone();
        let sort_order = self.panes[idx].sort_order;
        let grouping = self.panes[idx].grouping;

        let filter = todotxt_core::Filter::from_query(filter_query.trim());
        let mut filtered: Vec<(usize, &todotxt_core::Task)> = self.task_list.filter(&filter).into_iter().collect();

        if sort_order != SortOrder::FileOrder {
            filtered.sort_by(|(_, a), (_, b)| sort_order.compare(a, b));
        }

        let new_rows: Vec<DisplayRow> = if grouping && !filtered.is_empty() {
            let mut rows: Vec<DisplayRow> = Vec::new();
            let mut last_key: Option<String> = None;
            for (source_index, task) in &filtered {
                let key = group_key_for(task, &sort_order);
                if last_key.as_deref() != Some(&key) {
                    rows.push(DisplayRow::GroupHeader(key.clone()));
                    last_key = Some(key);
                }
                rows.push(DisplayRow::Task(*source_index));
            }
            rows
        } else {
            filtered
                .into_iter()
                .map(|(source_index, _)| DisplayRow::Task(source_index))
                .collect()
        };

        let pane = &mut self.panes[idx];
        pane.display_rows = new_rows;
        if pane.selected >= pane.display_rows.len() && !pane.display_rows.is_empty() {
            pane.selected = pane.display_rows.len() - 1;
        } else if pane.display_rows.is_empty() {
            pane.selected = 0;
        }
    }
}
```
