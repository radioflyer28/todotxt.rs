```rust
    /// Save view state to `tui-state.toml` on clean exit (Phase 43, PRSV-01/03).
    ///
    /// Builds a `Vec<PaneConfig>` from the current runtime panes and compares it against
    /// `startup_pane_snapshot`. If anything changed, writes all panes atomically to
    /// `tui-state.toml` beside `config.toml` (D-02, D-03). If panes are unchanged,
    /// skips the write to avoid spurious I/O (D-05).
    ///
    /// No-op when `config_path` is `None` (test harness or headless mode).
    /// `config.toml` is NEVER written here (PRSV-03).
    pub fn save_view_state(&self) -> color_eyre::Result<()> {
        let current: Vec<crate::config::PaneConfig> = self
            .panes
            .iter()
            .map(|pane| crate::config::PaneConfig {
                label: pane.label.clone(),
                filter: pane.filter_query.clone(),
                sort: crate::config::PaneSort::from_sort_order(pane.sort_order),
                group: pane.grouping,
                group_by: Some(pane.group_by),
            })
            .collect();

        if current == self.startup_pane_snapshot {
            return Ok(()); // Nothing changed — skip write (D-05)
        }

        if let Some(path) = &self.config_path {
            let state_path = crate::config::state_file_path(path);
            crate::config::TuiStateFile { panes: current }.save(&state_path)?;
        }

        Ok(())
    }
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem→main.rs | tui-state.toml read at startup — same trust level as config.toml |
| app.rs→filesystem | tui-state.toml written on exit — contains only pane view preferences |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-04 | Tampering | startup config.panes override | accept | Worst-case: attacker sets malicious filter string in tui-state.toml. Filter strings are only used as task display filters, never executed as commands. `toml::from_str` rejects malformed input, returning None and falling back to config.toml. |
| T-43-05 | Tampering | save_view_state write path | accept | State path derived from trusted `config_path` via `state_file_path()`; no user-controlled path injection. |
| T-43-06 | Denial of Service | save_view_state on exit | accept | Atomic write failure returns `color_eyre::Result::Err` which propagates to `run()` then `main()` — exits with error message. Acceptable: this is an exit path. |
</threat_model>
