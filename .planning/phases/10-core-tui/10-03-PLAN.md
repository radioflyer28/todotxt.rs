<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Full Phase 10 Core TUI implementation:
- j/k/arrows move selection up/down one row
- g jumps to first task, G jumps to last task
- Ctrl+d / Ctrl+u scroll half a page down / up
- x and u toggle the selected task done/incomplete and save immediately
- Status bar at bottom: filename, task counts, due today, overdue, key hints
- Completed tasks displayed with DIM modifier
- Selected task highlighted with REVERSED colors
  </what-built>
  <how-to-verify>
1. Run the TUI against a sample todo.txt file:
   ```
   cargo run -p todotxt-tui -- path/to/your/todo.txt
   ```
   (Or use any .txt file with a few tasks.)

2. Verify navigation:
   - Press j / ↓ — selection moves down one row
   - Press k / ↑ — selection moves up one row
   - Press G — selection jumps to last task
   - Press g — selection jumps to first task
   - Press Ctrl+d — selection jumps ~half page down
   - Press Ctrl+u — selection jumps ~half page up
   - Selection does NOT go out of bounds at first/last task

3. Verify done/undo:
   - Select an incomplete task, press x — task shows as done (DIM), file updated
   - Select that done task, press x — task reverts to incomplete, file updated
   - Press u on an incomplete task — same toggle as x

4. Verify status bar:
   - Bottom row shows: `{filename} | {N} tasks | {V} visible | {D} due today | {O} overdue  q quit | x done | j/k nav`
   - Counts are correct for your file

5. Press q or Ctrl+C — clean exit, terminal restored
  </how-to-verify>
  <resume-signal>Type "approved" if everything works, or describe any issues found</resume-signal>
