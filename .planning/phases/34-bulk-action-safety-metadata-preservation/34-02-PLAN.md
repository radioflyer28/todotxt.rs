  <behavior>
    Test 1 — with_priority sets new priority, preserves all other fields:
      Input: Task::parse("(B) 2025-12-01 fix login bug @work @home +proj1 +proj2 due:2026-03-01 t:2026-02-01")
      Call: .with_priority(Some('A'))
      Assert:
        - priority == Some('A')
        - creation_date == Some(2025-12-01)
        - due_date == Some(2026-03-01)
        - threshold_date == Some(2026-02-01)
        - projects == ["proj1", "proj2"]
        - contexts == ["home", "work"]  (sorted)
        - completed == false
        - to_raw() starts with "(A) "
        - to_raw() contains "due:2026-03-01" exactly once
        - to_raw() does NOT contain "(B)"

    Test 2 — with_priority(None) clears priority, no '(' token in raw:
      Input: Task::parse("(A) 2025-12-01 fix login bug @work +proj1 due:2026-03-01")
      Call: .with_priority(None)
      Assert:
        - priority == None
        - to_raw() does NOT contain "("
        - creation_date == Some(2025-12-01)
        - due_date == Some(2026-03-01)
        - projects == ["proj1"]
        - contexts == ["work"]

    Test 3 — with_priority on completed task preserves x prefix and completion_date:
      Input: Task::parse("x 2026-01-15 2025-12-01 fix login bug @work +proj1 due:2026-03-01")
      (Note: completed tasks have priority stripped per spec — so this task has no priority)
      Call: .with_priority(Some('C'))
      Assert:
        - completed == true
        - completion_date == Some(2026-01-15)
        - creation_date == Some(2025-12-01)
        - priority == Some('C')
        - to_raw() starts with "x 2026-01-15 (C) "
        - due_date == Some(2026-03-01)
        - projects == ["proj1"]
        - contexts == ["work"]

    Test 4 — with_due_date replaces existing due: — no duplicate tokens:
      Input: Task::parse("(A) 2025-12-01 fix login bug @work +proj1 due:2026-03-01 t:2026-02-01")
      Call: .with_due_date(Some(NaiveDate::from_ymd_opt(2026, 6, 15).unwrap()))
      Assert:
        - due_date == Some(2026-06-15)
        - to_raw() contains "due:2026-06-15"
        - to_raw() does NOT contain "due:2026-03-01"  ← no duplicate
        - priority == Some('A')
        - threshold_date == Some(2026-02-01)
        - projects == ["proj1"]
        - contexts == ["work"]
        - to_raw().matches("due:").count() == 1  ← exactly one due: token

    Test 5 — with_due_date(None) removes due: token:
      Input: Task::parse("(A) 2025-12-01 fix login bug +proj1 due:2026-03-01")
      Call: .with_due_date(None)
      Assert:
        - due_date == None
        - to_raw() does NOT contain "due:"
        - priority == Some('A')
        - projects == ["proj1"]

    Test 6 — with_priority preserves projects and contexts (no dedup corruption):
      Input: Task::parse("(B) 2025-12-01 fix bug @work @home +proj1 +proj2")
      Call: .with_priority(Some('Z'))
      Assert:
        - priority == Some('Z')
        - projects == ["proj1", "proj2"]  (sorted, no duplicates added)
        - contexts == ["home", "work"]    (sorted, no duplicates added)
        - to_raw() contains "+proj1" and "+proj2"
        - to_raw() contains "@work" and "@home"
