**Step 5 — Add `render_append_text_confirm` method** (place after `render_priority_picker_overlay` from Plan 01 or after `render_date_picker_overlay`):

```rust
/// Render the bulk append count confirmation banner (D-06, Phase 34, Plan 03).
fn render_append_text_confirm(&self, frame: &mut Frame, footer_area: ratatui::layout::Rect) {
    use ratatui::layout::Rect;
    use ratatui::style::{Modifier, Style};
    use ratatui::widgets::{Block, Borders, Paragraph};

    let n = self.append_confirm_count;
    if n == 0 { return; }

    let text = format!("Appending to {} tasks — Enter to continue, Esc to cancel", n);
    let popup_width = (text.len() as u16 + 4).min(frame.area().width);
    let popup_area = Rect {
        x: footer_area.x,
        y: footer_area.y.saturating_sub(3),
        width: popup_width,
        height: 3,
    };

    let paragraph = Paragraph::new(text)
        .block(Block::default().borders(Borders::ALL).title(" Bulk Append "))
        .style(Style::default().add_modifier(Modifier::BOLD));

    frame.render_widget(ratatui::widgets::Clear, popup_area);
    frame.render_widget(paragraph, popup_area);
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user keypress → AppendTextConfirm → AppendText | Mode transitions driven by keyboard input |
| date string from picker → NaiveDate parse → with_due_date() → disk | Date parsing from controlled UI suggestions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-06 | Tampering | NaiveDate::parse_from_str in date picker refactor | mitigate | Parse with explicit format `"%Y-%m-%d"` — dates come from app-generated suggestions (not user-typed input), so format is controlled; parse error returns an `Err` propagated via `?` operator |
| T-34-07 | Tampering | AppendTextConfirm → AppendText transition | accept | Selection preserved on Esc (D-03); no data mutated until Enter is pressed in AppendText editor |
| T-34-08 | Denial of Service | append_confirm_count overflow | accept | usize bounded by task list size (~thousands); no unbounded growth |
</threat_model>
