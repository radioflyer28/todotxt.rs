  <name>Task 1: Add recurrence parser tests</name>
  <files>crates/todotxt-core/src/task.rs</files>
  <behavior>
    Add focused tests for supported `rec:` interval syntax:
    - strict examples like `rec:+1d`, `rec:+2w`, `rec:+1m`, `rec:+1y`.
    - relative examples like `rec:1d`, `rec:2w`, `rec:1m`, `rec:1y`.
    - malformed tokens such as `rec:`, `rec:+`, `rec:abc`, and `rec:+0d` produce no recurrence.
  </behavior>

    distinguish strict and relative modes and preserve unsupported `rec:` tokens as plain
    task text without panicking.
  </action>

  <behavior>
    Add tests proving:

  </verify>
