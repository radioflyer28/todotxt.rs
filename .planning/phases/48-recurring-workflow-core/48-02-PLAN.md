Current CLI completion loop in `run_do`:

```rust
let updated = task.with_completed(true);
list.update(idx, updated.clone())?;
renderer.print_write_result(&format!("Completed task #{}.", idx + 1), idx, &updated);
```

Important behavior:

- IDs are validated before mutation.
- Indices are sorted descending before update to keep user-facing IDs stable.
- Completing an already-completed task is skipped.
