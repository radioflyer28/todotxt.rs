# Phase 32 Plan 01: Post-Audit Pane UX and Delete Polish

## Goal

Capture and close the manual UAT findings discovered after the v1.4 milestone audit passed so the pane milestone can be archived without known UX regressions or ambiguous controls.

## Scope

- Harden pane hotkeys and startup hydration behavior.
- Polish pane headers, label editing, and grouped header navigation.
- Clarify status/footer semantics and narrow-terminal behavior.
- Remove visual task indices while preserving internal canonical indices.
- Stabilize delete behavior, crash resistance, and key aliases.
- Add regression coverage for all new UAT-discovered bugs.

## Tasks

- [x] Restore exact-modifier hotkey matching so Ctrl+N/Ctrl+W/Ctrl+P do pane actions instead of falling through to plain bindings.
- [x] Rebuild all panes on startup so non-active panes are populated before focus moves.
- [x] Add inline pane-label editing from the pane header and allow empty labels.
- [x] Show pane header metadata using label, filter, and sort state with grouped-navigation access back to the header.
- [x] Scope status metrics to the active pane's filtered task set and make narrow terminal wrapping/truncation cleaner.
- [x] Hide visible task indices while keeping canonical indices for selection, edit, delete, and multi-select behavior.
- [x] Fix post-index-removal action targeting regressions and stale-index delete crashes.
- [x] Make single-task delete immediate, keep confirmation only for multi-delete, and add Delete/Backspace aliases.
- [x] Add regression tests covering hotkeys, startup hydration, pane label editing, grouped header navigation, duplicate-task deletes, and delete aliases.
