<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
All Phase 19–22 features are implemented and tests are passing. Verification docs, Nyquist files, requirements, roadmap, and changelog have been updated. This checkpoint verifies the features work correctly in a live TUI session.

Run the TUI with: `cargo run -p todotxt-tui -- --file /path/to/your/todo.txt`

You'll need a todo.txt file with several tasks (5–10 is enough) to test multi-select and bulk actions.
  </what-built>
  <how-to-verify>
Work through each verification item below. You don't need to test every edge case — just confirm the core flow works.

**1. Multi-select + bulk delete (BULK-01, SEL-01, SEL-02)**
- Press `j`/`k` to navigate to a task
- Press `v` to enter selection mode (you should see cursor behavior unchanged)
- Press `Space` to select the task, navigate to another, press `Space` again
- Press `D` — confirm you see "Delete 2 tasks?  y=confirm  any=cancel"
- Press `n` to cancel (tasks should remain, selection cleared)
- Repeat with tasks you're okay deleting, press `y` to confirm deletion

**2. Bulk append (BULK-02)**
- Select 2–3 tasks with `v` + `Space`
- Press `T` — confirm an "Append: " text input appears at the bottom
- Type some text (e.g. "+test") and press Enter
- Verify the text was appended to all selected tasks

**3. Help overlay (PAR-02, KEY-03)**
- Press `?` — confirm a centered help overlay appears with keybindings in 5 sections
- Verify the sections: Tasks, Filter, View, Select, App are visible
- Press `Esc` or `q` to close

**4. Smart normalization (NORM-01)**
- Edit a task (press `e`) and add "(A)" somewhere in the middle of the text
- Save (Enter) — verify the task is saved with `(A)` priority at the prefix position

**5. Keymap config (KEY-01) — optional but recommended**
- Add to your config.toml: `[keymap]` section with `help = "h"` (if `h` isn't already used)
- Restart the TUI
- Press `h` — confirm the help overlay opens instead of the filter toggle

**6. Selection count indicator (BULK-03)**
- Select 3 tasks with `v` + `Space`
- Confirm the status bar shows "| 3 selected"
- Press `Esc` to clear selection, confirm count disappears

**Parity reference:**
Deliberate deviations from todotxt.net are in `.planning/phases/22-keymap-help-parity/DEVIATION.md` — review if any behavior seems unexpected.
  </how-to-verify>
  <resume-signal>Type "approved" if all core workflows verified. Or describe any issues found and I'll investigate.</resume-signal>
