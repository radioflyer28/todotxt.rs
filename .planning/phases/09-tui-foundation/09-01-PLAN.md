```toml
path = "src/main.rs"
```

Note: `todotxt-core` uses `{ path = ... }` (not workspace) because it has a `features` override. The `watching` feature flag is required per D-05 and enables `FileWatcher` in core.

```rust
    Ok(())
}
```

This minimal main compiles cleanly and proves the dependency chain works. It will be replaced in Plan 03.
