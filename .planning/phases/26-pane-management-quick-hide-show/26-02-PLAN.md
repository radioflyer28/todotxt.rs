<objective>
Implement a global pane visibility toggle (Ctrl+P) that hides all panes and renders a single-pane view, while preserving all pane structure, count, and state (filter/sort/group) for instant restore. The hidden state is session-only (not persisted). Purpose: Allows users to quickly focus on a single task view without losing their multi-pane layout configuration. Output: panes_hidden field on App, pane_hide_toggle() method, render logic to check visibility flag and adapt UI accordingly.
</objective>
