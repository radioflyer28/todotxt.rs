Implement pane lifecycle hotkeys (Ctrl+N to create, Ctrl+W to delete) with guardrails, auto-labeling, and proper focus management. New panes are labeled 'Pane N' using a monotonic counter, appended to the right, and focus shifts to them. Deletion removes the active pane with adjacent focus shift and index normalization.

Purpose: Enables users to dynamically manage multi-pane layouts at runtime, create new filtered views with a single hotkey, and remove panes cleanly.

Output: pane_add() and pane_delete() methods, Ctrl+N and Ctrl+W hotkey registration and dispatch, pane auto-labeling and counter tracking.
</objective>

```rust
pub fn pane_delete(&mut self) {
    if self.panes.is_empty() {
        return;
    }
    let focus_index = if self.active_pane > 0 {
        self.active_pane - 1
    } else if self.panes.len() > 1 {
        0
    } else {
        0
    };
    self.panes.remove(self.active_pane);
    for (idx, pane) in self.panes.iter_mut().enumerate() {
        pane.id = idx;
    }
    self.active_pane = focus_index;
    self.reconcile_active_pane();
}
```
