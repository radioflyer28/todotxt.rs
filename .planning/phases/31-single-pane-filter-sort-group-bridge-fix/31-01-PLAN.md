In the `rebuild_and_reanchor()` method at app.rs:1622, add a global-field sync block **before** calling `rebuild_display_indices()`. The fix is to detect when in single-pane or panes_hidden mode and copy the active pane's query state to the global fields so `rebuild_display_indices()` will use the correct values.

**Current code structure (abbreviated):**
```rust
fn rebuild_and_reanchor(&mut self) {
    let old_canonical = if !self.should_show_single_pane() && self.panes.len() > 1 {
        // multi-pane old_canonical capture
        ...
    } else {
        self.canonical_selected()
    };

    self.rebuild_display_indices();  // ← reads global self.filter_query, self.sort_order, self.grouping
    
    // per-pane rebuild (Phase 25)
    if !self.should_show_single_pane() && self.panes.len() > 1 {
        self.rebuild_visible_rows();
        // reanchor logic
    }
    // ...
}
```

**Required fix:**
Add this block immediately before `self.rebuild_display_indices();`:

```rust
    // GAP-1 fix (Phase 31): sync global fields from active pane when in single-pane or hidden mode
    // In multi-pane mode, rebuild_visible_rows() uses per-pane fields directly.
    // In single-pane or panes_hidden mode, rebuild_display_indices() (global path) is used,
    // so we must sync the global state to match the active pane before calling rebuild_display_indices().
    if self.should_show_single_pane() || self.panes_hidden {
        let pane = &self.panes[self.active_pane];
        self.filter_query = pane.filter_query.clone();
        self.sort_order = pane.sort_order;
        self.grouping = pane.grouping;
    }
```

Insert this immediately before the call to `self.rebuild_display_indices();`.

**Why this works:**
- Multi-pane mode: `should_show_single_pane() == false && panes.len() > 1` → skips the sync, uses `rebuild_visible_rows()` (per-pane path)
- Single-pane mode (default): `should_show_single_pane() == true` → syncs global from active pane, then `rebuild_display_indices()` uses correct values
- Panes hidden: `panes_hidden == true` → syncs global, `render_panes()` routes to `render_task_list()` (global path)
- Empty/invalid state: `reconcile_active_pane()` already ensures `self.panes[self.active_pane]` is always valid
