Current core filter shape:
```rust
pub enum FilterTerm {
    Include(String),
    Exclude(String),
    Done,
    NotDone,
    DueToday,
    DuePast,
    DueFuture,
    DueActive,
    NegDueToday,
    NegDuePast,

    NegContextPrefix(String),
    NegProjectPrefix(String),
}

pub fn from_query(q: &str) -> Self
pub fn matches_with_date(&self, task: &Task, today: NaiveDate) -> bool
```

Existing parsing rules to preserve:
- whitespace-separated tokens are AND-combined
- `DONE` and `-DONE` are case-sensitive
- `due:*` tokens are case-insensitive
- `@foo` and `+foo` without slash are hierarchical prefix filters
- slash-delimited tags fall through to exact substring include/exclude


    Add:
    ```rust
    fn parse_token(token: &str) -> Option<FilterTerm> {
        if token.contains('|') {
            let inner: Vec<FilterTerm> = token
                .split('|')
                .filter(|part| !part.is_empty())
                .map(Self::parse_single_token)
                .collect();

            return match inner.len() {
                0 => None,
                1 => inner.into_iter().next(),
                _ => Some(FilterTerm::Or(inner)),
            };
        }

        Some(Self::parse_single_token(token))
    }
    ```

    Update `from_query` to use `filter_map(Self::parse_token)`.

    ```rust
    FilterTerm::Or(inner) => inner.iter().any(|term| Self::eval_term(term, task, raw, today)),
    ```
