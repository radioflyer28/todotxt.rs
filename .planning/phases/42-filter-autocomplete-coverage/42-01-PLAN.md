```rust
fn update_autocomplete(&mut self) {
    let line = self.editor.lines().first().cloned().unwrap_or_default();
    let trigger_pos = line.rfind(['@', '+']);
    if let Some(pos) = trigger_pos {
        let trigger = line.chars().nth(pos).unwrap();
        let prefix = &line[pos + 1..];
        if prefix.contains(' ') { self.autocomplete = None; return; }
        let prefix_lower = prefix.to_lowercase();
        let all_tokens = self.collect_tokens(trigger);
        let filtered: Vec<String> = all_tokens.into_iter()
            .filter(|t| t.to_lowercase().starts_with(&prefix_lower))
            .collect();
        // ...
        self.autocomplete = Some(AutocompleteState::new(trigger, prefix.to_string(), filtered));
    } else {
        self.autocomplete = None;
    }
}
```

<feature>
  <name>compute_filter_autocomplete</name>
  <files>crates/todotxt-tui/src/app.rs</files>
  <behavior>
    Given `(line: &str, cursor_col: usize, task_list: &TaskList, history: &VecDeque<String>)`:

    Cursor-word extraction:
    - Extract `before_cursor = &line[..cursor_col.min(line.len())]`
    - Find `word_start` = last whitespace in `before_cursor` + 1 (or 0 if none)
    - `word = &before_cursor[word_start..]`

    Token trigger detection (D-01, D-03):
    - If `word` starts with `@` or `+` (trigger char):
      - `prefix = word[1..]` (text after trigger, may be empty)
      - `prefix_lower = prefix.to_lowercase()`
      - Load candidates: `get_existing_contexts(task_list)` (for @) or `get_existing_projects` (for +)
      - Sort candidates, filter to those where `t.to_lowercase().starts_with(&prefix_lower)`
      - If filtered is empty → return None
      - Return Some(AutocompleteState::new(trigger, prefix.to_string(), filtered))

    No trigger fallback (D-01):
    - If no trigger found, check history:
      - If `history` is non-empty: return Some(AutocompleteState::new_filter_history(line.to_string(), history.iter().cloned().collect()))
      - If empty: return None

    Test cases:
    - ("", 0, _, empty_history) → None
    - ("@", 1, task_list_with_contexts, _) → Some(TokenAutocomplete('@'), prefix="", items=[all contexts])
    - ("@w", 2, task_list_with_["work","waiting"], _) → Some(TokenAutocomplete('@'), prefix="w", items=["waiting","work"] sorted+filtered)
    - ("@work", 5, task_list, _) → Some(TokenAutocomplete('@'), prefix="work", ...)
    - ("done:false @w", 13, task_list_with_contexts, _) → Some(TokenAutocomplete('@'), prefix="w")
    - ("@work ", 6, task_list, _) → no trigger (cursor on space → word is "" → no trigger) → FilterHistory or None
    - ("+p", 2, task_list_with_projects, _) → Some(TokenAutocomplete('+'), prefix="p")
    - ("just text", 4, _, non_empty_history) → Some(FilterHistory)
    - ("just text", 4, _, empty_history) → None
    - ("@xyz", 4, task_list_with_no_xyz_contexts, _) → None (filtered is empty)
  </behavior>
  <implementation>
    Add `compute_filter_autocomplete` as a free function (module-level, NOT an impl App
    method) in the autocomplete helpers section of app.rs (after the `// ── Autocomplete
    helpers ──` comment block, around line 2235).

    Signature:
    ```rust
    fn compute_filter_autocomplete(
        line: &str,
        cursor_col: usize,
        task_list: &TaskList,
        history: &std::collections::VecDeque<String>,
    ) -> Option<AutocompleteState>
    ```

    Implementation sketch:
    1. `let end = cursor_col.min(line.len());`
    2. `let before_cursor = &line[..end];`
    3. `let word_start = before_cursor.rfind(char::is_whitespace).map(|i| i + 1).unwrap_or(0);`
    4. `let word = &before_cursor[word_start..];`
    5. `let trigger_opt = word.chars().next().filter(|&c| c == '@' || c == '+');`
    6. If trigger_opt is Some(trigger):
       - `let prefix = &word[1..];`
       - `let prefix_lower = prefix.to_lowercase();`
       - Load candidates (sorted Vec<String> from get_existing_contexts or get_existing_projects)
       - `let filtered: Vec<String> = candidates.into_iter().filter(|t| t.to_lowercase().starts_with(&prefix_lower)).collect();`
       - If filtered.is_empty() → return None
       - return Some(AutocompleteState::new(trigger, prefix.to_string(), filtered))
    7. Else if history is non-empty:
       - return Some(AutocompleteState::new_filter_history(line.to_string(), history.iter().cloned().collect()))
    8. return None
