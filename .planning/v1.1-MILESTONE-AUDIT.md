## Gaps Found

### ❌ TUI-UX-02 — Auto-reload debounce exceeds 500ms

**Severity:** Blocker (requirement specifies 500ms)  
**File:** `crates/todotxt-core/src/watcher.rs` line 58  
**Fix:** `Duration::from_secs(1)` → `Duration::from_millis(500)` (one-line change)

The user confirmed "reload feels fast" during Phase 13 human verify, but the actual debouncer interval is 1 second — 2× the specified requirement. The user likely experienced the reload and estimated it as ≤500ms without measuring. The code evidence is definitive.

### ⚠ TUI-ACT-02 — `u` key no longer undoes completion

**Severity:** Spec drift (functional capability retained via x)  
**Background:** Phase 10 implemented `u=toggle_done` to undo completion. Phase 11 remapped `u` to edit mode for consistency with todotxt.net conventions (where u=edit is the established muscle memory).  
**Capability:** `x` on a completed task marks it incomplete — the undo capability still exists.  
**Resolution options:** Accept as intentional override (x satisfies the spirit), or add a dedicated undo-completion keybind.
