### Cross-Phase Issues

**Issue 1: Depth-1 undo semantics in composed flows (medium)**
- If a user adds a task then immediately applies a quick-setter (`@`/`+`), a single Ctrl+Z reverts only the setter mutation, not the add. This is architecturally correct (depth-1 by design) but may surprise users expecting undo to revert the "whole action."
- No test validates this composed-action boundary behavior.
- Affected: CAP-01, UNDO-01, TAG-01

**Issue 2: VIEW-03 regression suite gaps (medium)**
- `view_continuity_test.rs` covers add/edit/delete/toggle and hierarchical filter but does not directly call: date picker handler, priority picker handler, quick setter handler, clipboard paste, or bulk append confirm.
- Integration confidence for these paths in view-state preservation is based on static code inspection, not test execution.
- Affected: VIEW-03, CAP-03, CAP-04, TAG-01, TAG-02, CLIP-02, BULK-01
